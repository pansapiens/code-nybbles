# Hello, Rust

## Every program starts at `main`

```rust
fn main() {
    println!("Hello, world!");
}
```

- `fn` starts a function. `main` is the function Rust runs first.
- The function body goes between `{` and `}`.
- `println!` prints a line of text. The `!` means it's a **macro**, not a regular function.
- Each statement ends with `;`.
